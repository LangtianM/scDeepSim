\noindent\textbf{Property definitions.}
\begin{description}
  \item[Mechanistic de novo simulation.] Generates synthetic cells from an
  explicitly specified statistical or biological mechanism, without fitting the
  joint distribution of an external reference dataset.
  \item[Learned population distribution.] Fits a generative distribution to
  reference cells and can sample synthetic cells without requiring a matched
  observed cell as input at generation time.
  \item[Learnable nonlinear structure] Uses trainable nonlinear models, such as
  neural networks, to learn complex structure rather than relying
  only on a prespecified parametric form.
  \item[Tunable targeted intervention.] Exposes a parameterized biological or
  technical axis along which a designated property can be varied to generate
  matched families of datasets while non-target properties are preserved.
\end{description}
