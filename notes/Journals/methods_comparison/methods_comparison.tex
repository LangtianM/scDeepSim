\noindent\textbf{Property definitions.}
\begin{description}
  \item[De novo simulation.] Generates new samples from a learned distribution without requiring a matched observed sample.
  \item[Flexible learning.] Uses a flexible learned generative model to capture complex multivariate structure in reference single-cell data.
  \item[Continuous control] Provides numeric controls for effect magnitude, progression, noise, or signal strength.
  \item[OOD manipulation.] Moves samples into interpolated or extrapolated regimes not directly observed in the reference data, such as stronger-than-observed batch effects, shifted developmental states, or new factor combinations.
  \item[Disentangled factor control] Changes one factor while preserving the effect of others.
\end{description}
